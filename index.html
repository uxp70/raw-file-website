⚙️ GitHub Pages storage setup (one time)

GitHub Pages is static-only — it can't run an upload server. So this page stores uploads inside your own repo via the GitHub API, which gives you real raw links like https://raw.githubusercontent.com/OWNER/REPO/BRANCH/uploads/… that work everywhere. GitHub enforces 100 MB per file — truly unlimited sizes need the self-host server.js (see README).

Create token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → select this repo → Contents: Read and write. Token stays in your browser localStorage only.
