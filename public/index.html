❓ What is a “raw link”?

It's a link that opens the file itself — not a preview page. You can send it to anyone, post it anywhere, or embed it (for example, an image link works directly in a post).

Example: …

Every link on this site is the file itself — no preview pages, no download buttons. Big files are stored in small pieces — a few minutes after upload you get a raw link (the file itself, e.g. github.com/…/releases/download/…/my-app.ipa). Perfect for repo and package-manager URLs.
